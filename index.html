ต้นไม้หมวดหมู่สถานที่ (Tree)

สถานที่ท่องเที่ยวถูกจัดเป็น ต้นไม้มีราก 4 ระดับ (Level 0–3) — หน้าต่างเลือกต้นทาง/ปลายทางด้านบน คือการเดิน Path จาก Root ลงไปหา Leaf ทีละชั้น ส่วนสถานที่ที่เป็น Leaf ทุกแห่งคือ Vertex ในกราฟเส้นทางของหน้า 2–3 ลองคลิกโหนดเพื่อดู Parent / Child / Path หรือกดปุ่มเพื่อดู Tree Traversal

Root Parent (Internal node) Leaf = สถานที่ โหนดบน Path ที่เลือก
กดปุ่ม Preorder / Postorder / BFS เพื่อดูลำดับการเยี่ยมชมโหนด

Tree นี้แทนโครงสร้างอะไร?

แทน "หมวดหมู่ของสถานที่ท่องเที่ยว" — ลูกแต่ละตัวเป็นการแบ่งย่อยของโหนดแม่ เช่น เที่ยวสงขลา → ทะเลและธรรมชาติ → ชายทะเลสงขลา → หาดสมิหลา

Tree ไม่มีวงจร และระหว่าง Root กับ Leaf ใด ๆ มี Path เพียงเส้นเดียว จึงเหมาะกับข้อมูลที่แบ่งเป็นลำดับชั้น ส่วนการเดินทางที่มีหลายทางเลือกใช้ Graph แทน
